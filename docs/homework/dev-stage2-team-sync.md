входит.

## Договорённости

1. На защите используем терминологию PO (STG/DDS/DDM, названия `mart_*`,
   нумерацию FR/NFR) — чтобы речь всех троих звучала как один проект, а
   не три отдельных доклада.
2. Iceberg в DDS обосновываем критерием Vendor Lock-in 5/5 из Battle-card
   PO (Задание 1): открытый формат, данные переносимы без смены модели,
   при этом эксплуатация не тяжелее — один лёгкий REST-контейнер, без
   Trino/Spark/metastore.
